## 🐛 How to Report a Bug
If you encounter a bug, connection issue, or app crash, we want to know! 
Please go to the **[Issues](../../issues)** tab and click **New Issue**. 

To help us fix the problem faster, please include:
1. **App Version:** (e.g., Blue Proxy Browser v1.2.0)
2. **Device Model & OS:** (e.g., Samsung Galaxy S23, Android 13)
3. **Description:** What happened? What did you expect to happen?
4. **Steps to Reproduce:** How can we replicate the error?
5. **Screenshots:** (If applicable)
